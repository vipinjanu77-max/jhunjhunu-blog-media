# Jhunjhunu Blog — post media

Public image host for scheduled Instagram/Facebook posts (Metricool fetches images from here).
- `posts/<date>/<ID>_feed.png` (1080x1350) and `<ID>_story.png` (1080x1920)
- `brand/jb_render.py` renders the cards; fonts are Google Fonts (OFL).
Content and sources: see the Approval Queue sheet, tab "Fact Posts".
